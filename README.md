# VELOCIA — Automotive Showcase Platform

A modern web-based platform for exploring cars, discovering vehicle details, and managing customer enquiries through an administrative dashboard.

## Overview

VELOCIA provides an intuitive interface for users to explore vehicles, search according to their preferences, and submit test-drive enquiries. It also features an admin dashboard for managing vehicle listings, users, reviews, and customer enquiries.

## Features

- **Car Discovery:** Browse and explore available vehicles.
- **Smart Search:** Search by make, body type, budget, and model.
- **Recently Viewed Cars:** Revisit previously explored vehicles.
- **Test Drive Booking:** Submit test-drive requests and enquiries.
- **Admin Dashboard:** Manage vehicle listings and platform activity.
- **User Management:** View registered users.
- **Review Management:** Manage customer reviews and feedback.
- **Enquiry Management:** Review customer enquiries and contact details.
